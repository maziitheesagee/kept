# Kept – habit tracker

Single-file web app (HTML/CSS/JS, no build step).

Run: open `index.html` in a browser, or host it on any static host (Netlify, Vercel, GitHub Pages).

Note: accounts and habits are stored in the browser's localStorage, so they stay on one device.
For real accounts and sync across devices, add a backend (e.g. Supabase).
